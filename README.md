# رواء | Rawaa

شريط جانبي زجاجي قابل للتخصيص لنظام ويندوز 11، بواجهة عربية وخط المراعي

- وضع مصغر بايقونات ووضع موسع بالاسماء والبحث والمجموعات
- اختصارات للتطبيقات والملفات والمجلدات والروابط مع السحب واعادة الترتيب
- مساحات عمل بعناصر مشتركة ومثبتة واختصارات فرعية بكبسة يمين
- ازرار تفتح عدة عناصر وتوزع نوافذ تطبيقات ويندوز المدعومة على الشاشات
- وضع ثابت او ظهور من الحافة مع اختيار جهة الشريط لكل شاشة واخفاء تلقائي بملء الشاشة
- ساعة وتقويم شهري والوان دافئة او تيل وحجم وشفافية قابلة للتعديل
- حفظ محلي وتصدير واستيراد وايقونة بجانب ساعة ويندوز

## التشغيل والبناء

- نسخة Windows x64 من [Releases](https://github.com/BaselGhanem/Rawaa/releases) بعد نشرها
- للتطوير استخدم Node.js 22 ثم `npm ci` و`npm start`
- لتجهيز المثبت على ويندوز شغل `npm run dist`
- مسار الاعدادات الافتراضي هو `%APPDATA%\rawaa\rawaa.json`

## النوافذ والتحديث

ترتيب النوافذ والانتقال للتطبيق المفتوح يعتمد على تطابق مسار عملية نافذة Win32 مع ملف التطبيق او هدف اختصار LNK. البرامج اللي بتشغل نافذتها من عملية مختلفة قد تحتاج اختصار مباشر لملفها التنفيذي. ويندوز ممكن يمنع انتقال التركيز بين بعض التطبيقات.

التحديث يقرأ بيانات GitHub Releases من النسخة المثبتة. لنشر تحديث ارفع نسخة جديدة في `package.json` وملف القفل ثم ادفع وسم مطابق مثل `v1.0.1`. مسار البناء يرفع المثبت وبيانات التحديث للاصدار نفسه.
